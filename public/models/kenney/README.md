# Kenney models

A selection of models from asset kits by Kenney (https://kenney.nl), all released
under Creative Commons Zero (CC0); each folder keeps the kit's own `License.txt`.

- `cars/`: Car Kit 3.1 (https://kenney.nl/assets/car-kit)
- `trees/`: Nature Kit (https://kenney.nl/assets/nature-kit)
- `street/`: City Kit (Roads) (https://kenney.nl/assets/city-kit-roads)
- `trains/`: Train Kit (https://kenney.nl/assets/train-kit)
- `boats/`: Watercraft Kit (https://kenney.nl/assets/watercraft-kit)
- `houses/`: City Kit (Suburban) (https://kenney.nl/assets/city-kit-suburban)
- `props/`: Holiday Kit (https://kenney.nl/assets/holiday-kit), the bench only

The files are unmodified. Sizes, orientation and leaf colours are adjusted at load time in
`src/models.ts`.
